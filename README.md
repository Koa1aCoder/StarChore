# StarChore
A playful Parent dashboard to manage kids' chores, track progress, and celebrate their hard work with earned rewards.

## Development

This is a [Next.js](https://nextjs.org) app.

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view the app.

The site is built as a static export (`output: "export"`) and deployed to GitHub Pages via [.github/workflows/nextjs.yml](.github/workflows/nextjs.yml).
